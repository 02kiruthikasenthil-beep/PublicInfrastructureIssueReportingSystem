# Functional Requirements

## FR-01 Authentication
Users can register and log in.

## FR-02 Report Issue
A citizen can submit title, description, category, and location.

## FR-03 View Issues
A citizen can see their submitted issues.

## FR-04 Issue Details
A user can view issue information and status history.

## FR-05 Status
An authorized officer/admin can update issue status.

## FR-06 Reference Data
Categories and departments can be listed.

## Review-I boundary
FR-01 to FR-05 are implemented at MVP level. Advanced administration and AI are deferred.
